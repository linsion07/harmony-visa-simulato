# 签证模拟器 (Visa Simulator)

基于 HarmonyOS ArkTS 开发的签证申请模拟应用，纯本地运行，无网络交互，仅供娱乐学习使用。

---

## 功能特性

### 基础信息填写
- 姓名、护照号码输入
- 面签城市选择（成都崇州、成都武侯、北京海淀、广州越秀、香港九龙）
- 签证类型选择（旅游、探亲、商务）
- 证件照片上传（调用系统相册）

### 补充信息问卷
- 资产状况填写（万元）
- 纳税状态记录
- 出境记录（首次/多次）
- 在职/在学状态
- 邀请函/担保函上传
- 国籍与居留证明（非中国籍申请人）

### 审核模拟
- 模拟签证审核进度条动画
- 基于条件的自动审批逻辑
- 生成签证结果与识别码
- 可停留时长随机分配（五年多次/一年多次/三年多次）

### 隐私保护
- 应用启动时显示隐私条款弹窗
- 所有数据仅存储于本地设备
- 不连接网络，不上传任何数据
     
## 技术栈

| 技术 | 说明 |
|------|------|
| HarmonyOS | 鸿蒙操作系统 |
| ArkTS | 鸿蒙应用开发语言 |
| ArkUI | 声明式 UI 框架 |
| API 9+ | 最低 API 版本要求 |
